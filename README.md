
# InternNova Homepage Redesign

A modern, responsive homepage redesign for InternNova, created as part of my web development internship assignment.

## 🌐 Live Demo

[View Live Website](https://rajputsamriddhi1-0.github.io/InternNova-Homepage-Redesign/)

## 📌 Project Overview

The InternNova Homepage Redesign project focuses on creating a professional, visually appealing, and user-friendly homepage. The design aims to improve content presentation, navigation, readability, and the overall browsing experience across desktop, tablet, and mobile devices.

## ✨ Key Features

- Modern and professional homepage design
- Responsive layout for different screen sizes
- Structured navigation and section links
- Internship programs and technology domains sections
- Interactive elements powered by JavaScript
- Consistent typography, spacing, and visual hierarchy
- Organized HTML, CSS, JavaScript, and asset files

## 🛠️ Technologies Used

- **HTML5** — Semantic page structure
- **CSS3** — Styling, layouts, and responsive design
- **JavaScript** — DOM manipulation and interactive functionality
- **Git** — Version control
- **GitHub** — Source code hosting
- **GitHub Pages** — Website deployment

1. Clone the repository:

   ```bash
   git clone https://github.com/rajputsamriddhi1-0/InternNova-Homepage-Redesign.git
   ```
